# Tentación Ibérica — Web

Sitio estático (una sola página) con la carta de Tentación Ibérica.

- `index.html`: la página completa (HTML + CSS + JS, sin build).
- `menu.json`: la carta en formato datos (copiada de la carta digital, 26/11/2026). Ya va embebida en `index.html`.

Para verla local: abrir `index.html` en el navegador.
Publicada con GitHub Pages desde la rama `main`.
