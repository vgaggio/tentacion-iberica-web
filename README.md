# Tentación Ibérica — Web

Sitio estático (sin build) con la carta de Tentación Ibérica y pedidos por WhatsApp.

- `index.html` — carta, ubicación y contacto.
- `pedido.html` — armado del pedido; genera el mensaje y abre WhatsApp (+54 9 3518 04-7675).
- `menu.js` — la carta (la usan las dos páginas). `menu.json` es la misma data en JSON.
- `styles.css` — estilos compartidos.
- `img/` — fotos de productos (de la carta digital del local), logo y favicon.

**Cambiar el logo:** reemplazar `img/logo.png` (se usa en portada, pie y página de pedido).
**Cambiar precios/productos:** editar `menu.js`.

Publicado con GitHub Pages desde `main`: https://vgaggio.github.io/tentacion-iberica-web/
